# Escopo de Clientes

Painel estilo n8n para montar o escopo de um projeto na frente do cliente.

Abra `index.html` no navegador (não precisa instalar nada, funciona offline).

- O bloco inicial é o **cliente**: nome da empresa, nicho e observações.
- **+ ligar novo bloco** cria uma página/funcionalidade já conectada.
- Puxe a bolinha da direita de um bloco até outro para ligar (ou solte no vazio para criar um bloco novo).
- Enter cria um novo item na lista; Backspace num item vazio apaga.
- Duplo clique no fundo cria um bloco solto. Clique numa ligação para removê-la.
- Tudo salva sozinho no navegador. Em **Projetos** você alterna entre clientes.
- **Exportar**: escopo em texto (.md), imprimir/PDF, arquivo .json (backup/importar) e duplicar como modelo.
